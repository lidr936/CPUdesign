# 实验二实施计划

**目标：** 在 `lab2/` 内完成五级流水线 miniRV、AXI SoC、Cache/I-O 和最终集成；保留不能在当前环境执行的 Vivado、Trace、下板验收入口。

**架构：** `pipeline_cpu` 只验证 CPU 的取指/数据访问契约；`axi_soc` 只验证单周期核到 AXI/外设的契约；`integrated_soc` 把已验证的流水线核与 SoC 组合。三者共用 Lab1 的 RTL 功能基线，但绝不回写 `lab1/`。

**技术栈：** Verilog-2001、Vivado/XSim、Basic Trace/AXI Trace、Python 3 静态检查、课程提供的 ICache/DCache。

## 实施状态（2026-07-22）

- 已完成：三个工作副本、五级流水线 CPU、AXI 主控、Cache 接入、`RUN_TRACE`
  主存直连、单周期/流水线 SoC 集成与 Trace 同步脚本。
- 已验证：Lab2-A Basic Trace，单周期 AXI SoC Trace，最终流水线 AXI SoC 的
  Cache-off 和 Cache-on Trace；每项均覆盖 45 个本地 Trace 程序。
- 手动保留：Vivado 时钟/Block Memory/AXI Crossbar/外设 IP、C_TEST、串口下载、
  下板、CoreMark/LLAMA2、综合与时序报告。步骤见
  `板级与I_O手动验收清单.md`。

## 全局约束

- 所有新增实验二文件放在 `lab2/`；不修改 `lab1/miniRV_basic_ego1/miniRV_basic`。
- 继续使用 miniRV、EGO1 和既有 36 条指令实现。
- `cpu_core` 必须保持既有取指、数据访问和 `RUN_TRACE` 调试信号契约。
- 流水线为 IF/ID/EX/MEM/WB 五级；分支预测固定为默认不跳转。
- AXI 主控同一时刻只接受一个事务，仲裁优先级固定为 DCache 写、DCache 读、ICache 读。
- 只提交 HDL、约束、COE、测试和文档；不提交 Vivado 生成物或 IP 缓存。
