## 已修复

### P1: Cache 请求可能被同时接受

`axi_master` 早期在空闲态同时向 ICache 和 DCache 置 `ready`。Cache 的旁路状态机
会先看到 `ready`，下一拍才输出请求；两个 Cache 同时有请求时，低优先级请求可能已
离开请求态但未被 AXI 主机锁存。

已改为 `GRANT_D -> CHECK_D -> GRANT_I -> CHECK_I` 两阶段授权。每个窗口只给一类
Cache `ready`，下一拍采样该 Cache 的请求。数据 Cache 仍优先于指令 Cache。

修复后重新构建最终流水线 SoC，并运行全部 45 个本地 AXI Trace 程序，均输出
`Test Point Pass!`。
