## Lab2-A Basic Trace

将 `pipeline_cpu/miniRV_pipeline/src/rtl` 同步到 `cdp-tests/mySoC` 后，以下
程序均显示 `Test Point Pass!`：

```text
add addi and andi auipc beq bge bgeu blt bltu bne div divu jal jalr
lb lbu lh lhu lui lw mul mulh mulhu or ori rem remu sb sh sll slli
slt slti sltiu sltu sra srai srl srli start sub sw xor xori
```

`start` 同时输出数码管序列 `0x25000000` 至 `0x25000025`，随后通过。

## 最终流水线 AXI SoC

`integrated_soc/miniRV_pipeline_axi` 将 Lab2-A 的流水线核与 Lab2-B 的
Cache/AXI 层组合。下列两种配置均对上述 45 个程序全部通过：

- `defines.vh` 保持默认，禁用 ICache/DCache 的 Cache-off 配置。
- 临时定义 `ENABLE_ICACHE` 和 `ENABLE_DCACHE` 的 Cache-on 配置；Trace 使用
  `cdp-tests/vsrc/ram.v` 内置的 `blk_mem_gen_1` 行为模型。

实际命令：

```bash
cd cdp-tests
PATH=/usr/bin:$PATH make run TEST=addi
for test in add addi ... xori; do
  PATH=/usr/bin:$PATH make run_for_python TEST="$test"
done
```
