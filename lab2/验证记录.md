程序均显示 `Test Point Pass!`：

```text

lb lbu lh lhu lui lw mul mulh mulhu or ori rem remu sb sh sll slli
```

## 最终流水线 AXI SoC

`integrated_soc/miniRV_pipeline_axi` 将 Lab2-A 的流水线核与 Lab2-B 的
Cache/AXI 层组合。下列两种配置均对上述 45 个程序全部通过：

- `defines.vh` 保持默认，禁用 ICache/DCache 的 Cache-off 配置。
- 临时定义 `ENABLE_ICACHE` 和 `ENABLE_DCACHE` 的 Cache-on 配置；Trace 使用
  `cdp-tests/vsrc/ram.v` 内置的 `blk_mem_gen_1` 行为模型。

实际命令：

```bash
cd cdp-tests
PATH=/usr/bin:$PATH make run TEST=addi
for test in add addi ... xori; do
  PATH=/usr/bin:$PATH make run_for_python TEST="$test"
done
```

## C_TEST0 Cache-off 下板

验证日期：2026-07-30。使用自建 `miniRV_pipeline_axi` SoC，保持
`ENABLE_ICACHE` 和 `ENABLE_DCACHE` 关闭。将
`c_test_rv_stu/0_uart_test/main.coe` 写入 `bram_axi` 后重新生成并烧录
bitstream。

- 串口配置为 115200、8N1、无流控，Phase 0 输出 `Hello World!`。
- Phase 1 可接收并回显单字符。
- 收到字符后 LED 以 ASCII 位图变化，EGO1 数码管显示对应 8 位十六进制值；例如
  `A` 显示为 `00000041`。

该项证明自建 Cache-off bitstream 下 C_TEST0 的 CPU、BRAM、Crossbar、UART、LED
和 Dig 路径可用。它不证明 `1_formatIO_test`、排序、Timer、拨码开关、Cache-on、DDR、
CoreMark 或 LLAMA2。
